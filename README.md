Vivek AI – Gemini-Powered Intelligent Chat Assistant

Vivek AI is an interactive AI chatbot application developed using Python, Streamlit, and Google Gemini. The application provides a user-friendly conversational interface where users can ask questions and receive AI-generated responses in real time. It maintains conversation history during the session and streams Gemini's responses progressively for a smoother chat experience.

The application also includes customizable AI settings such as model selection, response creativity (temperature), and optional system instructions. Users can start a new conversation whenever required. The interface is enhanced with custom CSS, a responsive sidebar, chat bubbles, avatars, gradients, and an interactive chat input to create a modern AI-assistant experience.

The project uses environment variables to securely load the Google Gemini API key rather than placing the key directly in the Python application.

Main technologies
Python — application programming language
Streamlit — web interface
Google Gemini — AI language model
python-dotenv — environment-variable management
HTML/CSS — custom visual design
Session State — conversation and chat configuration management
Streaming — displays Gemini responses progressively
